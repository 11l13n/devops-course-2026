# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветки создаются быстро и практически не требуют дополнительных ресурсов. Ветка представляет собой указатель на определённый коммит.

В SVN ветвление реализуется через копирование директорий репозитория, поэтому работа с ветками менее удобна.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN использует централизованную архитектуру, поэтому для выполнения коммита необходимо подключение к центральному серверу.

В Git коммиты можно создавать локально без подключения к интернету, поскольку у разработчика есть собственная полная копия репозитория.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может использоваться в старых проектах, инфраструктура и процессы которых уже построены вокруг этой системы. Например, SVN может встречаться при сопровождении legacy-проектов, в том числе в государственных организациях и банках.
