# Мой пет-проект

Идея: Приложение To-Do List с графическим интерфейсом для управления списком задач. Пользователь сможет добавлять новые задачи, отмечать их как выполненные и удалять ненужные задачи.

Стек: Python, Tkinter, SQLite

Цель: Научиться создавать приложения с графическим интерфейсом на Python и реализовать взаимодействие пользователя с приложением.
